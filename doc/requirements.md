# myPhotoWorks — Requirements

> 개인용 사진 일괄 리사이즈/보정 도구
> 기준일: 2026-03-28

---

## 1. 사용 목적

- 개인 사진을 일괄로 리사이즈 및 보정 처리
- 두 가지 워크플로우 지원:
  1. **일괄 적용**: 옵션 설정 후 전체 파일에 한 번에 처리
  2. **미리보기 개별 확인**: 한 장씩 Before/After 비교하며 설정 조정 및 저장

---

## 2. 워크플로우

```
파일 선택 → 보정/리사이즈 옵션 설정 → [미리보기] 또는 [일괄 적용]
```

---

## 3. 메인 창 레이아웃

```
┌─────────────────────────────────────────────┐
│  [파일추가] [폴더추가] [선택제거] [전체제거]         │  ← 상단 파일 선택 영역
├───────────────────┬─────────────────────────┤
│                   │                         │
│  파일 리스트        │  (파일 선택 후 썸네일 등)  │
│  (스크롤 가능)      │                         │
│  (넓게 배치)        │                         │
│                   │                         │
├───────────────────┴─────────────────────────┤
│  [보정] 탭  │  [리사이즈] 탭  │  [출력] 탭       │  ← 하단 탭 (3개만)
│  ...                                        │
└─────────────────────────────────────────────┘
          [미리보기] [일괄 적용]
```

- 기존 탭 중 Frame / Signature / Configuration / Help 제거
- 파일 리스트 영역을 기존보다 더 크게 배치
- 참고 이미지: `doc/reference/photoworks_main.png`

## 4. 기능 상세

### 4-1. 보정 (Effects)

| 기능 | 설명 |
|---|---|
| Auto Level | 체크박스로 on/off |
| Auto Contrast | 체크박스로 on/off |
| 밝기 (Brightness) | +- 수치 입력 |
| 대비 (Contrast) | +- 수치 입력 |

### 4-2. 리사이즈 (Resize)

| 항목 | UI | 설명 |
|---|---|---|
| 리사이즈 여부 | 체크박스 | 체크 해제 시 리사이즈 없음 |
| 기준 축 | 드롭다운 | 긴축 / 짧은축 |
| 픽셀값 | 숫자 직접 입력 + 드롭다운 프리셋 | 프리셋: 1080 / 1920 / 2048 / 2560 / 3840 |
| 비율 유지 | 자동 | 나머지 축은 자동 비율 계산 |

### 4-3. 출력 (Output)

| 항목 | 옵션 |
|---|---|
| 저장 경로 | ① 첫 번째 파일 기준 `output` 폴더 ② 각 파일별 `output` 폴더 ③ 직접 지정 경로 |
| 파일명 | 원본 파일명 유지 + prefix / suffix 추가 옵션 |
| 포맷 | JPG 고정 |
| JPG 품질 | 슬라이더 + 숫자 직접 입력, 1~100% |
| EXIF | 보존 (항상) |

## 5. 미리보기 창

### 5-1. 레이아웃

```
┌─────────────┬─────────────┬─────────────┐
│  Before     │  After-A    │  After-B    │
│  (원본)      │  [⚙ 설정]   │  [⚙ 설정]   │
│             │             │             │
└─────────────┴─────────────┴─────────────┘
│  EXIF 정보 패널 (우측 또는 하단)              │
├────────────────────────────────────────┤
│  [이전]  [다음]  기타 버튼                  │
└────────────────────────────────────────┘
```

- **Before**: 원본 이미지 (보정 없음)
- **After-A / After-B**: 독립적인 보정 설정 적용 화면
  - 초기값: 메인 창에서 설정한 값
  - 각 이미지 하단에 설정 패널 항상 표시 (⚙ 버튼 없음, 인라인 표시)
  - 설정 변경 시 해당 창에 실시간 반영
  - 이전/다음 이동 시 각 창의 설정값 유지
- 이미지는 창 크기에 맞게 자동 축소
- **EXIF 정보 패널**: 별도 창으로 띄우는 방식, 위치 이동 가능 (플로팅 창)
- **일괄 처리 진행**: 프로그레스 바로 표시
- 참고 이미지: `doc/reference/photoworks_preview.png`

### 5-2. 단축키

| 키 | 보정 적용 | 리사이즈 적용 | 동작 |
|---|---|---|---|
| `1` | ❌ | ✅ | Before 기준 (리사이즈만) 저장 후 다음 |
| `2` | ✅ After-A 설정 | ✅ | After-A 기준 저장 후 다음 |
| `3` | ✅ After-B 설정 | ✅ | After-B 기준 저장 후 다음 |
| `Space` | — | — | 저장 없이 스킵, 다음으로 이동 |
| `Del` | — | — | 원본 파일 삭제 후 다음으로 이동 |
