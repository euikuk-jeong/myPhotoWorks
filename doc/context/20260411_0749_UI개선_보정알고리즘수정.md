## 작업 목록

### UI 개선 (main_window / thumbnail_panel)
- 메인 화면 메뉴바 제거

### 버그 수정
- PyQt6 6.10.x에서 `nativeEvent` 오버라이드 시 `super()` 호출로 인한 앱 크래시 수정
  - `return False, 0` 으로 대체 (super() 호출이 ACCESS_VIOLATION 유발)
- QSS `QCheckBox::indicator:checked::after { content: "" }` 제거
  - Qt 미지원 CSS 속성으로 시작 시 "Unknown property content" 경고 8회 출력 원인

### 미리보기 창 개선 (preview_window)
- 마우스 가운데 버튼으로 화면 맞춤 (Home 단축키와 동일 동작)
- 상태 표시 레이블(`counter_lbl`) 제거 → 윈도우 타이틀에 `N/전체 — 파일명` 표시
- 버튼 바를 컨테이너 위젯으로 래핑, 파란 그라디언트 배경 + 상단 구분선 적용

### 보정 알고리즘 수정 (effects.py)
- `auto_level`: 채널별 독립 스트레칭 → 루미넌스 기반 단일 LUT 적용
  - 기존: R·G·B 각각 다른 배율로 스트레칭 → 색상 캐스트(파란 색조) 발생
  - 변경: grayscale 히스토그램에서 lo/hi 산출 → 전 채널 동일 LUT 적용
- `auto_contrast`: 감마 커브 방식 → `ImageOps.autocontrast(cutoff=1)` 선형 스트레칭
  - 기존: 평균 밝기를 0.5로 끌어당기는 비선형 감마 커브
  - 변경: 1% 클리핑 후 min→0, max→255 선형 매핑 (표준 동작)

## 주요 결정 사항

- PyQt6 6.10.x에서 `nativeEvent`의 `super()` 호출이 크래시를 일으키므로
  미처리 메시지는 `return False, 0`으로 처리 (Qt가 계속 기본 처리 수행)
- `auto_level`의 색상 캐스트는 알고리즘 선택 문제 (버그 아님)였으며,
  레퍼런스 툴과 일치시키기 위해 루미넌스 기반 단일 LUT 방식으로 전환
- 세션 중 발생하는 Todo는 `doc/todo/todo.md`에서 통합 관리
