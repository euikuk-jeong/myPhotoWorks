## 작업 목록

### 1. exe 실행 오류 수정 (v0.9.4 릴리즈)
- **증상**: GitHub Release에서 배포된 exe 실행 시 `FileNotFoundError` 발생
  ```
  FileNotFoundError: 'C:\..._MEI43042\myphotoworks\ui\styles\glass_theme.qss'
  ```
- **원인**: `myphotoworks.spec`의 `datas`에 `ui/styles` 디렉토리 누락 → `glass_theme.qss`가 번들에 포함되지 않음
- **수정 파일**:
  - `myphotoworks.spec`: `datas`에 `myphotoworks/ui/styles` 항목 추가
  - `src/myphotoworks/ui/styles/__init__.py`: PyInstaller 번들 환경(`sys.frozen`)에서 `sys._MEIPASS` 기준으로 경로 계산하는 `_styles_dir()` 함수 추가

### 2. release-github 스킬 개선

#### 2-1. `--delete-branch` 제거
- **문제**: PR merge 시 `--delete-branch` 옵션으로 리모트 워킹 브랜치(`second_stage`)가 삭제됨
- **수정**: `gh pr merge` 명령에서 `--delete-branch` 옵션 제거

#### 2-2. pyproject.toml 버전 자동 업데이트 추가
- **문제**: 릴리즈 시 git 태그만 올리고 `pyproject.toml` 버전은 업데이트하지 않아 exe의 도움말 > 정보 다이얼로그에 구버전(0.9.2) 표시
- **수정**: 스킬 플로우 재구성
  - Step 2: 버전 결정을 커밋 전으로 이동 (기존 Step 6에서 앞당김)
  - Step 3 (신규): `pyproject.toml` `version` 필드를 릴리즈 버전으로 업데이트
  - Step 4: 커밋 시 `pyproject.toml` 포함

### 3. pyproject.toml 버전 정정 및 v0.9.5 릴리즈
- `pyproject.toml` 버전을 `0.9.2` → `0.9.5` 로 업데이트
- v0.9.5 릴리즈 수행 (PR #9)
