## 작업 목록

### 1. 이전 세션 잔여 버그 수정

### 2. FP1 파일 기반 레시피 로딩 구조 전환
- `src/fuji_fp1/` 폴더 신설 — Fujifilm FP1 XML 파일 보관 위치
  - 7종 샘플 파일 번들: `provia.fp1`, `velvia.fp1`, `astia.fp1`, `classic_chrome.fp1`,
    `pro_neg_hi.fp1`, `eterna.fp1`, `acros.fp1`
- `src/myphotoworks/recipes/fp1_parser.py` 신규 작성
  - `Fp1Parser.parse(path)` — FP1 XML → `RecipeData`
  - `Fp1Parser.parse_dir(folder)` — 폴더 스캔, 파일명 stem을 키로 dict 반환
  - FilmSimulation 문자열 매핑 (Provia/Velvia/Acros+R 등 변형 포함)
  - WB 프리셋 이름 → 켈빈 변환 (Auto/Daylight/Shade/Kelvin 모드)
  - 레거시 `<Saturation>` 태그 폴백 지원
  - 존재하지 않는 폴더·파싱 실패 파일 안전 처리
- `builtin_recipes.py` 수정
  - 하드코딩 레시피 상수 제거 → 임포트 시 `src/fuji_fp1/` 자동 스캔
  - `RECIPE_COLORS` 키: 파일명 stem → `FilmSim` 값 문자열로 변경
  - `recipe_color(recipe)` 헬퍼 함수 추가
  - `RECIPE_DISPLAY_ORDER`: FilmSim 표준 순서(Provia→Acros) 기준 자동 정렬
- `tests/test_fp1_parser.py` 신규 작성 (51개 테스트)
  - `_parse_film_sim`, `_parse_wb_kelvin` 단위 테스트
  - `Fp1Parser.parse()`: 각 필드 파싱, 레거시 태그, 오류 처리
  - `Fp1Parser.parse_dir()`: 멀티파일, 비FP1 파일 무시, 파싱 실패 스킵
  - 번들 FP1 파일 통합 검증 (`TestBundledFp1Files`)
