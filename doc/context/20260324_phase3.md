## 구현 목표

참고 이미지(`photoworks_main.png`)를 기반으로 메인 창 UI를 구성한다.
- 좌측: 썸네일 목록 패널

## 생성 파일

### `src/myphotoworks/ui/thumbnail_panel.py` — ThumbnailPanel

**역할**: 좌측 사진 목록. 썸네일 비동기 생성 + 드래그앤드롭 지원.

**주요 구성**
- `QListWidget` (IconMode) — 썸네일 크기 80×80 px
- `_ThumbnailLoader(QRunnable)` — QThreadPool로 백그라운드에서 썸네일 생성
  - Pillow로 이미지를 열어 80×80으로 축소 → QPixmap 변환 후 아이템에 반영
- 드래그앤드롭: `dragEnterEvent` / `dropEvent` 오버라이드
- 중복 파일·미지원 확장자 자동 필터링
  - 지원 포맷: `.jpg .jpeg .png .tif .tiff .bmp .webp`

**시그널**
| 시그널 | 발생 조건 |
|---|---|
| `photo_selected(PhotoItem)` | 썸네일 단일 클릭 |
| `photo_double_clicked(PhotoItem)` | 썸네일 더블 클릭 (→ 프리뷰, Phase 4) |

### `src/myphotoworks/ui/settings_panel.py` — SettingsPanel

**역할**: 우측 7탭 설정 패널. `AppSettings` 인스턴스를 소유하고 변경 시 시그널 발신.

**탭 구성**

| 탭 | 상태 | 주요 위젯 |
|---|---|---|
| **Home** | 완전 구현 | Filter, Auto Correction, Brightness/Contrast, Sharpen/Gaussian |
| **Output** | 완전 구현 | 출력 경로, 포맷(JPEG/PNG), 품질 슬라이더, 리사이즈 |
| Name | placeholder | — |
| Signature | placeholder | — |
| PPI | placeholder | — |
| Configuration | placeholder | — |
| **Help** | 구현 | QTextBrowser (사용법·단축키 HTML) |

**Home 탭 세부 구성**
```
[Filter]
  □ 흑백 조절
  Level  [0] ~ [255]

[Auto Correction]
  □ Auto Level 조절    □ Auto Contrast 조절

[Brightness / Contrast]
  Brightness  [──────────────] 0
  Contrast    [──────────────] 0

[Sharpen / Gaussian]
  □ Sharpener    □ Gaussi   ← 둘 중 하나만 선택 가능
```

**`_LabeledSlider` 헬퍼 위젯**
- `QSlider` + 현재값 `QLabel`을 가로로 묶은 재사용 컴포넌트
- `valueChanged(int)` 시그널 노출

**시그널**
| 시그널 | 발생 조건 |
|---|---|
| `settings_changed(AppSettings)` | 임의 설정값 변경 시 |

### `src/myphotoworks/ui/main_window.py` — MainWindow

**역할**: 전체 레이아웃 조립. 버튼·상태바·진행바 관리. 설정 및 창 크기 영속화.

**레이아웃 구조**
```
QMainWindow
└─ QVBoxLayout
   ├─ 버튼 바:  [Choose]  [Clear]  ··········  [처리 시작]
   ├─ QSplitter (Horizontal)
   │   ├─ ThumbnailPanel (좌, 고정 너비)
   │   └─ SettingsPanel  (우, 가변)
   └─ QStatusBar
       ├─ 상태 텍스트 (좌)
       └─ QProgressBar (우, 처리 중에만 표시)
```

**주요 동작**
| 버튼/이벤트 | 동작 |
|---|---|
| Choose | `QFileDialog.getOpenFileNames` → `ThumbnailPanel.add_photos()` |
| Clear | 썸네일 전체 삭제, 버튼 비활성화 |
| 처리 시작 | `BatchWorker` 생성·시작, 진행바 표시 |
| 썸네일 더블클릭 | 메시지박스 (Phase 4 이후 PreviewWindow로 교체) |
| 창 닫기 | 창 크기/위치를 `config.json`에 저장 |

**영속화 항목** (`~/.myphotoworks/config.json`)
- `last_open_dir` — 마지막으로 사진을 연 폴더
- `last_output_dir` — 마지막 출력 경로
- `window_geometry` — 창 크기·위치 (hex)

### `src/myphotoworks/workers/batch_worker.py` — BatchWorker

**역할**: 사진 일괄 처리를 UI 스레드와 분리하는 `QThread`.

**처리 흐름**
```
run()
  for photo in photos:
    photo.status = PROCESSING  → emit photo_done
    processor.process()        ← 이펙트 체인 적용
    processor.save()           ← 출력 경로에 저장
    photo.status = DONE/ERROR  → emit photo_done
    emit progress(i, total)
  emit finished()
```

**시그널**
| 시그널 | 타입 | 용도 |
|---|---|---|
| `progress` | `(int, int)` | 진행바 업데이트 |
| `photo_done` | `PhotoItem` | 썸네일 상태 배지 갱신 |
| `finished` | — | 처리 완료 후 버튼 복원 |
| `error` | `str` | 오류 메시지 상태바 표시 |
